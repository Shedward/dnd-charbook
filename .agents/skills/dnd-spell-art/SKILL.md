# Иллюстрации заклинаний

Работайте из корня dnd-charbook. Все пути ниже отсчитываются от него. Откройте `docs/illustrations/README.md` и выбранные профили в `docs/illustrations/profiles/`. Профили определяют лайаут, сюжет и рисовку независимо. Для обычной книги принято `vignette / effect-first / woodcut`. Для рамки в ксилографии используйте `full-face / effect-first / woodcut`.

Прочитайте `README.md` выбранного набора в `resources/illustrations/`. Для нового набора создайте краткий README с тремя профилями, параметрами публикации, нюансами промпта и командой проверки.

1. Найдите запись по ID в `resources/data/spellbook.json`. Определите видимое действие, реакцию и отличие от близких эффектов по `docs/illustrations/spell-registry.md`. Проверьте сценарий по выбранному профилю сюжета до генерации.
2. Для рамки экспортируйте индивидуальную маску и контрольное наложение из `books/debug/full-face-card.typ` по инструкции лайаута. Используйте одинаковые язык, вылет и масштаб текста для маски и финала. Для виньетки возьмите размеры из её профиля.
3. Соберите промпт, например для рамки:

   ```sh
   python3 scripts/spell-art-prompt.py augury --layout full-face --story effect-first --style woodcut \
     --mask build/full-face/augury-mask.png --scene 'A monk casts marked knucklebones before deciding whether to cross the bridge.'
   ```

   Передайте промпт генератору изображений вместе с маской данного заклинания и художественным референсом выбранного стиля. Для виньетки опустите аргумент маски. При доработке приложите исходный арт и укажите, какие элементы композиции следует сохранить.
4. До публикации откройте исходный PNG при увеличении. Проверьте принадлежность рук, ног и кистей, позу и хват. Проверьте лица: число и положение видимых глаз соответствуют анатомии существа и ракурсу головы, зрачки находятся внутри век и взгляд направлен к действию. У полноформатной карты сравните украшения с фиолетовыми ориентирами по верху и бокам. В синей полосе допуска проверяйте все четыре стороны и углы. Полезно мысленно или на превью сдвинуть рез на 2 мм внутрь: подошвы и значимые детали целы, фон пересекает полосу и продолжается за резом, а крайние ветви и кладка сохраняют читаемую форму. Осмотрите нижние миллиметры всего холста, включая углы: продолжение земли или пола заполняет вылет до последней строки пикселей. Для проверки смещений готовой карты используйте `books/debug/trim-proof.typ` по инструкции `docs/cards/masks.md`. Отметьте конкретные дефекты и после локальной правки проверьте снова.
5. Наложите настоящий текст в Typst. Сравните карты рядом после номинальной обрезки при физическом размере. У рамки проверьте свободное поле под последней строкой, читаемость жеста и связь земли под персонажами с окружением по краям. У виньетки проверьте масштаб и зазор над нижней линией. Исправьте арт при пересечении с текстом.
6. Храните исходники и итерации в `build/`. По инструкции лайаута опубликуйте фон с вылетом 2 мм через `scripts/spell-plates.py` (Python с Pillow). Передайте согласованный бриф через `--scene-file`: издатель сохранит его в PNG как `scene-prompt`. Для повторной генерации сборщик промпта принимает этот PNG через `--scene-from`. Готовый ресурс — один `resources/illustrations/<набор>/<id>.png`; для горизонтального рисунка скрипт рассчитывает холст и сохраняет координаты книжной виньетки. Выберите набор при сборке через `--input illustration-set=<набор>`. Эталон сравнения — `docs/illustrations/profiles/styles/woodcut/resources/woodcut-scenes.png`.
