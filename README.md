# D&D Charbook

Typst-шаблоны для настольной D&D 5e. Из описания персонажа получается книга A5 с характеристиками, атаками, инвентарём, заклинаниями и биографией. Для игры можно отдельно напечатать двустороннюю колоду заклинаний персонажа или целого класса.

## Первая сборка

Понадобится Typst CLI (проверено с 0.15.1). Для исходного оформления используются шрифты Mookmania, Alegreya SC и Nodesto Cyrillic. Из корня репозитория выполните:

```sh
mkdir -p build
typst compile books/marek-grivachov.typ --root . build/marek-grivachov.pdf
```

PDF появится в `build/`. Параметр `--root .` нужен для доступа к ресурсам проекта. Команда `./scripts/buildAll.sh` собирает каждый документ из `books/*.typ`. На macOS команда `./scripts/watch.sh marek-grivachov` откроет PDF в Skim и будет пересобирать его при изменениях.

## Свой персонаж

Создайте файл в `books/`. Функция `introduce` задаёт исходные данные, а каждый `upgrade` объединяет изменения от одного источника. Например, получение уровня может одновременно увеличить запас хитов и добавить заклинание.

```typ
#import "../dnd/builder/builder.typ": *
#import "../dnd/game/game.typ": CHA, spellcasting

#let hero = build(
  introduce(name: "Мира", stats: (STR: 8, DEX: 14, CON: 12, INT: 10, WIS: 13, CHA: 16)),
  upgrade("Колдун 1 ур.",
    setClass("Колдун"), levelUp(), addMaxHP(9),
    setSpellcasting(spellcasting(stat: CHA)),
    addSpellById("eldritch-blast"),
  ),
)
#charbook(hero, locale: "ru")
```

Полный пример с биографией, ячейками заклинаний и развитием по уровням — [книга Марека](books/marek-grivachov.typ). Если нужен свой порядок страниц, их можно компоновать вручную через `dnd.page`, как в [книге Эдны](books/edna-zeenhoffer.typ).

## Карточки заклинаний

Для колоды Миры замените последнюю строку примера на `#deckOfSpells(hero)` и задайте язык через `#setLocale("ru")`, импортировав `setLocale` из `../dnd/core/core.typ`. Для колоды класса достаточно отдельного файла:

```typ
#import "../dnd/core/core.typ": setLocale
#import "../dnd/builder/builder.typ": deckOfClassSpells

#setLocale("ru")
#deckOfClassSpells("жрец", subclass: "домен кузни")
```

Эта колода включает общие заклинания жреца и заклинания указанного подкласса. По умолчанию на лист A4 помещаются девять карточек. На лицевой стороне указаны игровые параметры, на обороте — описание. Для двусторонней печати переворачивайте лист по длинной стороне: порядок карточек на обороте уже отражён по горизонтали.

В новых сессиях Codex из этого проекта можно вызвать [навык `$dnd-spell-art`](.agents/skills/dnd-spell-art/SKILL.md). Например: «$dnd-spell-art, сделай рамку для Предзнаменования в стиле woodcut и покажи готовую карту». Рабочие экспорты находятся в `build/`, готовые фоны — в `resources/illustrations/<набор>/<id>.png`.

[Инструкция по генерации арта](docs/illustrations/README.md) позволяет отдельно выбрать лайаут карты, правила сюжета и художественный профиль. Например, для «Необнаружимости» можно сочетать полноформатную рамку, обычное сюжетное ревью и нуарный детектив. В инструкции есть команда для сборки промпта и ссылки на экспорт маски и печатную проверку.

Выберите набор для колоды через `--input illustration-set=woodcut-frames` или `deckOfAllSpells(illustrationSet: "woodcut-frames")`. По умолчанию собирается текстовая колода. Для локальных виньеток укажите `--input illustration-set=woodcut-vignettes`. Если в наборе нет заклинания, выводится обычная текстовая карта.

```sh
typst compile --root . --input illustration-set=woodcut-frames books/deck-test.typ build/frames.pdf
```

В `resources/illustrations/` хранится один финальный PNG на заклинание в наборе. Холст — 70,67 × 99,67 мм с вылетом 2 мм. Размер печати и пропорции общие для наборов. Разрешение PNG может различаться: упаковщик размещает исходник виньетки пиксель в пиксель, а полноформатный арт сохраняет разрешение генератора. Книга использует область виньетки из того же PNG; книжный набор включается через `--input book-illustration-set=<набор>`. Для публикации нужен Python с Pillow. Команды приведены в профилях [виньетки](docs/illustrations/profiles/layouts/vignette/vignette.md) и [рамки](docs/illustrations/profiles/layouts/full-face/full-face.md).

Для лицевой стороны можно задать [частичную цветовую схему](docs/cards/plate-format.md#цветовая-схема). Typst берёт цвета из метаданных PNG конкретной карты, затем из `style.json` набора. У остальных элементов сохраняется обычное оформление.

Проверить лицевую сторону всех заклинаний в русской колоде A4 (3 × 3, без персонажа) можно командой `./scripts/spells-check-front.sh`. Нужны Typst и jq. Скрипт выводит количество, названия и ID карточек, где текст пришлось сократить. Код выхода 0 означает, что всё поместилось, 1 — найдена обрезка.
