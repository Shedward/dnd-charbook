# Генерация иллюстраций для карт

**Стиль** — именованный набор в `resources/illustrations/<стиль>/`. **Эстетика** — переиспользуемый профиль рисовки и мира. Например, стили `woodcut-frames` и `woodcut-vignettes` используют одну эстетику `woodcut` с разными лайаутами. Новый стиль разрабатывают с помощью [скилла создания стиля](../../.agents/skills/dnd-art-style/SKILL.md).

Задание задают ID заклинания и три независимых выбора. Например, `nondetection / full-face / effect-first / noir` означает «Необнаружимость», полноформатная рамка, обычные правила сюжета, нуарный детектив. Текст на карту накладывает Typst.

| Ось | Что определяет | Доступные профили |
|---|---|---|
| Лайаут | Холст, области для рисунка и текста, отступы, способ экспорта и наложения | [`vignette` — нижняя виньетка](profiles/layouts/vignette/vignette.md), [`full-face` — иллюстрация до краёв карты](profiles/layouts/full-face/full-face.md) |
| Сюжет и персонажи | Какое действие показывает эффект, кто участвует, где уместна шутка, как отличить близкие заклинания | [`effect-first` — действие и реакция](profiles/stories/effect-first/effect-first.md) |
| Эстетика | Мир, облик героев и предметов, манера рисунка, палитра, характер перехода в бумагу | [`woodcut` — D&D в ксилографии](profiles/aesthetics/woodcut/woodcut.md), [`noir` — нуарный детектив](profiles/aesthetics/noir/noir.md), [Челябинск на мыльницу](profiles/aesthetics/chelyabinsk-snapshot/chelyabinsk-snapshot.md) |

**Принятая полноформатная серия** — `full-face / effect-first / woodcut`. Сначала сравните [маску с текстовым наложением](../cards/resources/ornament-guides.png), затем [готовые карточки после обрезки](profiles/aesthetics/woodcut/resources/woodcut-scenes.png). Маска задаёт поле текста, вылет, безопасную область и место для опционального орнамента. На готовом листе оценивайте читаемость действия, масштаб персонажей и связь нижней сцены с окружением вдоль краёв.

## От задания до печатной карты

1. Укажите три профиля. Для обычной колоды принято сочетание `vignette / effect-first / woodcut`. Каждый выбор можно заменить отдельно.
2. По ID прочитайте `body` и `description` в [каталоге](../../resources/data/spellbook.json). По правилам выбранного сюжета подготовьте сцену в двух предложениях. Для `effect-first` проверьте [соседние заклинания](spell-registry.md) и проведите отдельное ревью до генерации.
3. Из лайаута получите размеры, пространственный референс, если он нужен, и требования к полю текста. Для `full-face` экспортируйте маску именно этого заклинания с реальными языком, шрифтом и размером карты. Из эстетики возьмите художественный референс. При смене только эстетики сохраняйте ту же маску и согласованный сценарий.
4. Соберите запрос из трёх блоков `prompt` выбранных профилей и сцены. Маску подпишите как референс расположения, художественный образец — как референс рисовки. Передавайте сюжетные примеры словами, когда нужна только шутка. [Правила масштаба](profiles/scale.md) действуют для всей печатной серии.
5. Держите рабочий PNG в `build/`. Опубликуйте единый фон в `resources/illustrations/<набор>/<id>.png` и соберите пробу по командам лайаута. Прикройте название, проверьте эффект и конкурирующее прочтение. На масштабе 100 % проверьте силуэты, пропорции, читаемость текста, отсутствие пересечений с иллюстрацией и согласованность тона на листе. Если меняется текст полноформатной карты, обновите маску. Если меняется только палитра, вернитесь к профилю эстетики.

Для выбора цветов на светлой или тёмной иллюстрации см. [цветовую схему карты](../cards/plate-format.md#цветовая-схема).

## Приёмка иллюстрации

- В исходном PNG при увеличении проверьте [анатомию, хват и взгляд](profiles/scale.md). В месте перекрытия должно быть понятно, кому принадлежит кисть, стопа или даже призрачная рука.
- Для полноформатного woodcut совместите рисунок с маской того же заклинания. Проверьте свободные участки фиолетового пунктира над шапкой и с обеих сторон. Листья у линии реза относятся к внешнему окружению. [Примеры внутренних акцентов](profiles/aesthetics/woodcut/woodcut.md#лёгкое-обрамление-полноформатной-карты).
- На [печатном листе и пробе со смещением реза](../cards/masks.md#приёмка-при-смещении-реза) проверьте нижний вылет, целостность сюжетных деталей и читаемость настоящего текста. При каждой правке сохраняйте существующий `scene-prompt`, параметры текста и цветовую схему, если сам сюжет или оформление не менялись.

## Как продолжить набор

В каждой папке набора держите короткий `README.md` с ID трёх профилей, референсом руки художника, размерами, настройками цвета, исключениями для отдельных карт и командами сборки. При продолжении сверяйте список ID из тестовой книги с `index.json` выбранного набора. В готовом PNG храните только сюжетный бриф в UTF-8 (поле `scene-prompt`). Общие правила и параметры остаются в профилях и README. При публикации передайте `--scene-file build/art/<id>.txt` в `scripts/spell-plates.py`.

Чтобы собрать новый промпт по готовому рисунку, замените `--scene '…'` на `--scene-from resources/illustrations/<набор>/<id>.png`. Для этой команды нужен Pillow. Чтобы прочитать только сюжет:

```sh
python3 -c 'import sys; from PIL import Image; print(Image.open(sys.argv[1]).text["scene-prompt"])' resources/illustrations/woodcut-frames/scrying.png
```

## Пример запуска

Задача — показать, что магическое наблюдение пропускает защищённого человека. Сначала подготовьте [маску `nondetection`](profiles/layouts/full-face/full-face.md), затем соберите текст запроса:

```sh
python3 scripts/spell-art-prompt.py nondetection \
  --layout full-face --story effect-first --aesthetic noir \
  --mask build/full-face/nondetection-mask.png \
  --scene 'A detective sees a guest sitting on a bench. His scrying basin shows the same distinctive bench empty; he leans closer in disbelief.'
```

Команда выводит готовый промпт. Приложите указанные изображения в генераторе и сгенерируйте арт. Для нижней виньетки укажите `--layout vignette` и опустите `--mask`. Для ксилографии замените `--aesthetic noir` на `--aesthetic woodcut` и приложите «Пир». В полноформатной ксилографии используйте основной тёплый тон бумаги; для пробы с растушёвкой задайте светлое поле и мягкую границу из сохранённого образца.

## Добавить профиль

В каталоге нужной оси создайте папку с ID профиля, например `profiles/aesthetics/noir/`. Инструкция носит то же имя — `noir.md`. Изображения профиля лежат рядом в `resources/`. Сборщик находит профили по этим папкам. Укажите область ответственности, один блок `prompt` и критерий проверки. В лайауте с маской используйте маркер `{mask}`. В промпте эстетики путь к образцу задавайте относительно корня проекта. Добавьте ссылку в таблицу выше. Результат сравнивайте с предыдущим листом, варьируя одну ось за раз.

[Альбом проб эстетики](alternative-aesthetics/README.md) содержит дополнительные направления для будущих профилей.
