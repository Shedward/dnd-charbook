# Нуарный детектив · `noir`

Экспериментальный профиль. Действие разворачивается в мире сыщиков, свидетелей, кабинетов и ночных улиц. Роль из сценария выражайте знакомым этому миру занятием. Например, прорицатель может быть частным сыщиком, который проверяет видение в чаше; его занятие считывается по взгляду и потёртому пальто. Существо или магический предмет сохраняет свойства из каталога.

Референс — [нуарная «Необнаружимость»](resources/noir.png). Возьмите из неё жёсткий боковой свет, серебристые полутона, тёмные силуэты и сдержанную мимику. Для проб используйте нейтральное светлое поле под чёрным текстом. В полном формате деталями тёмного интерьера заполните разрешённые поля; света и засветы отпечатка могут растворяться в переходной полосе. В виньетке тот же приём работает по открытым краям силуэта.
