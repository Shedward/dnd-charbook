# Формат иллюстрированной карты

В `resources/illustrations/` каждый набор содержит полноразмерные PNG по ID заклинания и индекс для Typst. Печатный холст с вылетом 2 мм составляет 70,67 × 99,67 мм. Размер в пикселях зависит от исходника. При выборе набора Typst укладывает фон под текст и обрезает его по формату карты. Для книги скрипт публикации сохраняет в PNG координаты виньетки.

## Цветовая схема

После генерации посмотрите на фон именно под буквами. Если нужны цветовые акценты или светлая надпись на тёмном фоне, подготовьте JSON с нужными ролями. Укажите цвета в формате `#RRGGBB`.

| Роль | Что красит Typst на лицевой стороне |
|---|---|
| `title` | Название заклинания |
| `stats` | Обе строки параметров, включая уровень, компоненты, время, дальность, длительность и значки |
| `rules` | Основное описание, включая выделенные условия и стоимость компонентов |
| `divider` | Линии и ромб между разделами, вертикальные разделители параметров |
| `content-fill` | Однотонное поле под шапкой и текстом до конца защитного запаса. Без этой роли виден сам PNG. |

Если под текстом нужен один сплошной цвет, задайте его в теме (например, `"content-fill":"#F5EDDF"`) и оставьте эту область иллюстрации пустой. Typst нанесёт заливку поверх арта под буквами, учитывая реальную высоту текста и выемки маски. Фактура бумаги и переход в пейзаж могут оставаться частью рисунка.

Например, сохраните `{"title":"#FECB67","stats":"#CFDFE7","rules":"#F5EDDF"}` в `build/art/augury-colors.json`. Передайте файл при публикации:

```sh
python3 scripts/spell-plates.py woodcut-frames build/art/augury.png --color-scheme build/art/augury-colors.json
```

Скрипт записывает объект в текстовое поле PNG `color-scheme`. При переиндексации он заново читает эти метаданные. В `resources/illustrations/<набор>/style.json` можно задать общие цвета, например `{"color-scheme":{"title":"#842c26"}}`. Каждая роль берётся сначала из PNG, затем из набора. Если значение отсутствует в обоих местах, текст получает обычный цвет, а линии — стандартный вторичный. При отсутствии `content-fill` Typst оставляет поле без заливки. Для проверки соберите готовую карту и оцените мелкие параметры и основной текст при печатном размере.
