# Документация

- [Карточки и книга](cards/README.md) — собрать колоду, выбрать набор, получить маску для художника и настроить цвета текста.
- [Генерация иллюстраций](illustrations/README.md) — выбрать лайаут, сюжет и стиль, подготовить промпт и опубликовать фон.

Картинки для инструкций находятся в папке `resources/` рядом с документом-владельцем. Готовые фоны для Typst хранятся в локальных наборах в `resources/illustrations/`. Рабочие пробы и PDF собираются в `build/`.
